## Report a problem

Open an issue in the public GitHub repository and include the operating system, Relift version, command used, relevant redacted output, and whether the source was an image or a device. Do not attach private disk images, recovered files, credentials, or personal data.

Before reporting a limitation as a bug, check the support matrix and gap report. Recovery results are not guaranteed; all current validation evidence is synthetic.

## Data recovery safety

Stop using a drive after deletion. Do not write recovered output to the source device. Use a dry run first and verify that source and destination are different physical volumes. For physically damaged media, consider professional recovery services.

No commercial support, response-time guarantee, Discord, or Matrix service is currently offered.
