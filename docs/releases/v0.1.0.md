# Relift v0.1.0 Preview

Relift is an early open-source CLI and desktop GUI for recovering deleted files
from raw disk images and devices.

## What's included

- Windows, macOS, and Linux desktop bundles.
- CLI archives for Windows x86_64, macOS x86_64 and ARM64, and Linux x86_64 and ARM64.
- `SHA256SUMS`, generated from the release assets after all platform builds finish.

## Validation limits

The code has passed cross-platform CI and deterministic synthetic-image tests.
No real physical drive, real deleted volume, or representative real-world
recovery corpus has been validated. Recovery accuracy on actual media is
unknown. Check the [support matrix](../support-matrix.md) and
[verification record](../VERIFICATION.md) for what is and is not tested.

Do not rely on Relift as the only copy or recovery method for important data.
If a drive may be failing, stop using it and consider imaging it first. Always
write recovered data to a different physical volume. SSD TRIM, overwrites,
encryption, and file fragmentation can prevent or limit recovery.

## Unsigned downloads and checksums

All release assets are unsigned; Windows installers are not Authenticode-signed
and macOS bundles are not notarized. Operating systems may show security
warnings. The `SHA256SUMS` file lets you compare asset bytes with the published
manifest, but hashes alone do not authenticate the publisher. Obtain the assets
and manifest from the official GitHub release over HTTPS.

On Linux or macOS, download an asset and `SHA256SUMS` into the same directory,
then run:

```sh
sha256sum --check SHA256SUMS
```

On Windows, calculate the asset hash in PowerShell and compare it with the
matching entry in `SHA256SUMS`:

```powershell
Get-FileHash .\Relift_0.1.0_x64_en-US.msi -Algorithm SHA256
```

Package-manager submissions are not available for this preview.
